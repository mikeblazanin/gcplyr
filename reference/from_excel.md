# A function that converts base-26 Excel-style letters to numbers

A function that converts base-26 Excel-style letters to numbers

## Usage

``` r
from_excel(x)
```

## Arguments

- x:

  A `vector` of column names in Excel-style base-26 letter format (any
  values that are already in base-10 will be returned as-is)

## Value

A `vector` of numbers in base-10
